# JEE Question Generator & Prep Platform

A comprehensive, interactive web application for JEE (Main & Advanced) preparation. Features mock tests, chapter-wise questions, formula sheets, timer-based practice sessions, and progress tracking with full Dark/Light theme support.

## ✨ Features

- **PCM Syllabus Coverage**: Complete Physics, Chemistry, and Mathematics topics for Class 11 & 12.
- **Interactive Practice & Mock Tests**: Timed test simulation with instant scoring, answer key reviews, and detailed solutions.
- **Dark & Light Mode**: Built-in seamless theme switching.
- **Zero Backend Required**: Runs client-side; progress and test history are safely stored in browser LocalStorage.
- **Vercel-Ready**: Preconfigured with `vercel.json` for one-click deployment.

## 🚀 Deployment

### Deploy to Vercel
1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework Preset: **Other**.
3. Deploy!

### Run Locally
Open `index.html` directly in any modern browser, or serve it using any local static file server:
```bash
npx serve .
```
